## Git для новичков (часть 1)
* Git хранит историю проекта в виде **графа коммитов**: каждый коммит имеет уникальный hash и ссылается на предыдущую версию. Поэтому историю можно не только просматривать, но и сравнивать и возвращаться к нужному состоянию.
* Коммиты лучше делать не после каждого изменения файла, а после **законченного логического изменения** — например, отдельной функции или исправления ошибки. Так история проекта получается понятнее.
* Ветка — это не копия проекта, а отдельная **история изменений**, которая может развиваться независимо от других веток и позже объединяться с ними.
* `HEAD` — указатель на коммит, в котором Git сейчас находится. При переключении ветки меняется и положение этого указателя.
* Git работает локально, поэтому репозиторий и его история могут существовать на компьютере независимо от GitHub. GitHub используется как удалённое хранилище и место для совместной работы.
